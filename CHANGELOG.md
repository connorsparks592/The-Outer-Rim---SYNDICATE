# Changelog

## [1.3] - 2026-05-12

### Added
- Backstories system with unique perks/buffs (Street Rat, Kid Stuff, Wanted, Task Master, Lone Wolf).
- Factions & Reputation system (Hutt Cartel, Empire, Rebels, Local Settlers).
- Expanded Jabba's Palace with new locations: Jabba's Palace Entrance, Jabba's Throne Room, Dungeon, and Kitchen.
- Save Manager allowing management of up to 4 save slots and deletion of existing save game data.

### Fixed
- Improved cinematic timing and fixed Star Wars logo scaling.
- Fixed save game compatibility with updates (automatic migration).
